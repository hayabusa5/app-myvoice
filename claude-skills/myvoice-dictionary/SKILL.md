# マイ音声入力の辞書に登録する

Macのマイ音声入力(`/Applications/マイ音声入力.app`)に、URLで語を渡す。辞書はiCloudでiPhoneにも同期される。

## 登録のしかた

```bash
open "myvoice-mac://add-term?wrong=<誤変換>&right=<正しい表記>"
```

- `wrong` と `right` は必ずURLエンコードする(日本語・空白・記号があるため)。下のPythonの1行で作ると確実:

```bash
open "$(python3 -c 'import sys,urllib.parse as u;a=sys.argv[1:];print("myvoice-mac://add-term?"+"&".join(f"wrong={u.quote(a[i])}&right={u.quote(a[i+1])}" for i in range(0,len(a),2)))' 'クロードコード' 'Claude Code')"
```

- 組を続けて並べると、まとめて登録できる(上のPythonに `誤 正 誤 正 …` の順で渡す)
- `wrong` を空にすると、置き換えはせず、認識のヒントだけに使う語になる(正しく聞き取れているが、念のため覚えさせたい固有名詞)
- 同じ誤変換がすでにあれば上書きし、一番上に移す。上にある語ほど、Groqへの認識のヒントとして優先される
- 登録すると、Macの画面の下に「辞書に追加: 〇〇→△△」と出る

## 気をつけること

- 誤変換(`wrong`)は、音声入力が実際に出した表記を、そのまま入れる。ユーザーの話から推測できるときは聞き返さない
- 正しい表記が分からないとき(固有名詞の綴りなど)だけ確認する
- 人の名前・住所・勤務先・パスワードなどの個人情報は、ユーザーがはっきり頼んだときだけ登録する
- 登録したら、何を登録したか(誤変換 → 正しい表記)を一言で伝える
- アプリが入っていない・起動しないときは、`open` がエラーを返す。そのときは、その旨を伝える
